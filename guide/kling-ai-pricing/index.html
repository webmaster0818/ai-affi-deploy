Kling AIの料金プラン｜月払い・年払い・API料金とクレジット単価

Kling AIの有料プランは、Standard・Pro・Premier・Ultra+の4つです。2026年11月20日時点では月払い・年払いとも期間限定の割引が表示されており、割引が終わると金額が上がります。公式の会員プランページとAPI料金ページを確認し、割引中と割引後の金額、100クレジットあたりの単価、Kling 4.0の動画を作る経路ごとの費用をまとめました。

Kling AIの料金の概要

  • 有料プランは4つ：Standard（月660クレジット）・Pro（3,000）・Premier（18,000）・Ultra+（57,000）
  • 割引は期間限定：月払いは最初の3か月35%オフ、年払いは最初の1年50%オフ。割引後の金額もページに明記されています
  • 上位プランほど単価が下がる：100クレジットあたり、月払いの割引中で$0.98（Standard）〜$0.71（Ultra+）
  • 商用利用・透かし削除はStandard以上：無料のBasicは対象外です
  • Webの1本あたりの消費量は非公開：表示されているのは「Kling 4.0 720pは1秒$0.035から」という目安のみです
  • APIは別料金：前払いパッケージ（$500〜）で、Kling 4.0は出力1秒あたりのユニット課金です

APIの料金（開発者向け）

API料金ページ（2026年11月20日確認）では、Kling 4.0とKling 4.0 Flash用の前払いパッケージが3種類あります。どれも有効期限は180日で、繰り越し・延長はできません。

  • Standard Package 1：$500で3,250ユニット（2%オフ・1ユニット$0.15386）
  • Standard Package 2：$2,000で13,135ユニット（3%オフ・$0.15229）
  • Standard Package 3：$8,000で53,640ユニット（5%オフ・$0.14915）

Kling 4.0は、入力動画がない場合に出力1秒あたり720p 1.0／1080p 1.5／4K 3.5ユニットを消費します。HDRを有効にすると1080pで0.3、4Kで0.5ユニットが1秒ごとに加算されます。Kling 4.0 Flashは720pのみで0.6ユニット/秒です。Package 1の単価で計算すると、1080p・10秒は約$2.31、4K・10秒は約$5.39です（当サイト計算）。

どのプランを選ぶか

  • まず試したい：無料のBasic。ただし商用利用と1080p以上は対象外です
  • SNS用の動画を少しずつ作る：Standard。商用利用と透かしの削除が付きます
  • 毎週たくさん作る：Pro以上の年払い。100クレジットあたりの単価が下がり、Kling 4.0 720pの目安も1秒$0.035からになります

割引後の金額で考えると、年払いは月払いより約25%安くなります（Standardで$105.6→$79.2）。無料で使えるほかの動画生成AIは無料で使える動画生成AIのまとめで紹介しています。

よくある質問

Kling AIは無料で使えますか？＋

無料のBasicプランがあります。ただし公式の比較表では、Basicは1080p・4K動画の生成、ウォーターマークの削除、生成物の商用利用がいずれも対象外で、1回の生成で作れる動画は1本です。毎月付与されるクレジットの数は、比較表に記載がありません（2026年11月20日確認）。

有料プランはいくらからですか？＋

2026年11月20日時点の会員プランページでは、Standardが月払いで最初の3か月 月$6.5、4か月目から月$8.8です。年払いは最初の1年が$60、2年目から年$79.2と表示されています。どちらも期間限定の割引価格で、毎月660クレジットが付与されます。

Kling 4.0の動画1本で何クレジット使いますか？＋

Webアプリでの1回あたりのクレジット消費量は、会員プランページにも料金ページにも記載がありません。会員プランページには、年払いのProで「Kling 4.0 720p as low as $0.035/s」、Premierで「$0.033/s」という1秒あたりの目安だけが表示されています（2026年11月20日確認）。

商用利用できるのはどのプランですか？＋

公式の比較表では、生成物の商用利用（Generated content is for commercial use）とウォーターマークの削除は、Standard以上の有料プランが対象です。無料のBasicは対象外です。

APIの料金はWebのプランと別ですか？＋

別です。開発者向けAPIは前払いのパッケージ制で、$500（3,250ユニット）からです。Kling 4.0は出力1秒あたり720pで1.0ユニット、1080pで1.5ユニット、4Kで3.5ユニットを消費します。Webのサブスクリプションとは別に購入する仕組みです。
