Remotionとは？Claude Codeで動画を作る手順・料金・ライセンス

Remotionは、Webの画面づくりに使うReactのコードで動画を作るツールです。Claude CodeなどのAIエージェントにコードを書かせて、文章の指示から動画を作る使い方が広がっています。2026年11月20日に公式ドキュメントとライセンスを確認し、AIエージェントでの使い方、無料で使える条件、会社向けの料金をまとめました。

情報基準: 2026年11月時点
PR当サイトはアフィリエイトプログラムによる収益を得て運営しています。記事内の一部リンクは広告（アフィリエイトリンク）です。掲載している料金・報酬条件は 2026年11月時点 の公開情報にもとづいています。ご利用前に、各公式サイトにて最新情報をご確認ください。

Remotionの概要

  • Reactのコードで動画を作るツール：映像を生成するAIモデルではなく、文字・図形・画像・音声を組み合わせて書き出します
  • AIエージェント用のAgent Skillsを公式が提供：Claude Code・Codex・Cursorなどで使えます
  • 個人・3人以下の会社は無料：商用利用も可能で、機能の制限はありません
  • それ以外の会社は有料：手作業の制作は1席月$25、自動の量産は1レンダー$0.01（月$100から）

Remotionでできること

Remotionは、動画の1コマ1コマをReactの部品として書き、それをMP4などの動画に書き出すツールです。映像そのものをAIが描くのではなく、テキストのアニメーション、図解、地図の動き、字幕、データをもとにしたグラフなど、コードで表現できるものを組み合わせて動画にします。

  • 同じ型の動画の量産：データを差し替えて、商品紹介やランキングなどの動画を大量に作れます
  • プレビューと編集：Remotion Studioで、ブラウザ上で確認しながら直せます
  • 編集ソフトへの受け渡し：公式のスキルの説明では、編集可能なOpenTimelineIO形式のタイムラインとしても書き出せます

Claude Codeなどで動画を作る手順

Remotionの公式ドキュメント（2026年11月20日確認）は、AIエージェントに読ませる「Agent Skills」を公開しています。Claude Code・Codex・Cursor・Kimi Code・OpenCodeで使えるとしています。手順は次のとおりです。

  1. パソコンにNode.jsを入れる
  2. Agent Skillsを入れる：npx -y skills@latest add remotion-dev/skills -g -y
  3. 新しいプロジェクトを作る：npx create-video@latest（作成時にスキルの追加も選べます）
  4. エージェントに作りたい動画を指示する（例：公式の例文「レコード店のプロモーション動画を作って」）
  5. Remotion Studioで確認し、書き出す

公式のスキルには、プロジェクト作成（/remotion-create）、書き方の手本（/remotion-markup）、プレビュー（/remotion-studio）、書き出し（/remotion-render）、地図のアニメーション（/remotion-maps）、字幕（/remotion-captions）、ライセンス確認（/remotion-license）などがあります。ChatGPTのデスクトップアプリから作る方法も案内されています。

無料で使える条件

RemotionのライセンスとライセンスFAQ（2026年11月20日確認）では、次に当てはまる場合は無料で使えます。

  • 個人（私用・商用を問わない）
  • 3人以下の営利団体・チーム
  • 非営利団体（行政機関・教育機関などは書面の許可が必要）
  • 導入の検討中で、まだ商用で使っていない場合

無料ライセンスと会社向けライセンスに機能の差はなく、無料ライセンスの利用にアカウント登録や連絡は要りません。禁止されているのは、Remotionのコードを改変・複製して、自分の派生版として販売・貸与・再許諾することです。

※Remotion公式の「License & Pricing」ページ（最終更新2026年11月18日）で2026年11月20日に確認。自動化の開発者にはCreatorsの席は不要とされています。

料金の試算（当サイトの計算）

  • 社員10人の会社で、2人が手作業で動画を作る：Creators 2席＝月$50
  • 商品動画を月5,000本自動で作る：$0.01×5,000本＝$50ですが、最低料金のため月$100
  • 月30,000本自動で作る：$0.01×30,000本＝月$300

自動化は月10,000本までは最低料金の$100に収まる計算です。どの区分になるか迷う場合は、公式のライセンスFAQで確認するか、Remotionに問い合わせてください。

ほかの方法との使い分け

実写のような映像を作りたい場合は、Seedance 2.5やGoogle Flowのような動画生成AIが向いています。説明アニメーションをプロンプトだけで作りたい場合は、AnthropicのClaude Motionも選択肢です。Remotionは、同じ型の動画を量産したい場合や、文字・図解・データの見せ方をコードで細かく決めたい場合に向いています。

よくある質問

Remotionは無料で使えますか？＋

個人、従業員3人以下の営利団体、非営利団体は無料で使えます（商用利用も可）。機能の制限はなく、アカウント登録も不要です。それ以外の会社は、Company License（会社向けライセンス）の購入が必要です。

Remotionは動画生成AIですか？＋

Remotion自体は、Reactのコードで動画を組み立てて書き出すためのツールで、AIで映像を生成するモデルではありません。Claude CodeやCodexなどのAIエージェントにコードを書かせることで、指示文から動画を作る使い方が広がっています。

Claude Codeで使うにはどうすればよいですか？＋

公式ドキュメントでは、Node.jsを入れたうえで「npx -y skills@latest add remotion-dev/skills -g -y」でRemotionのAgent Skillsを入れ、エージェントに動画を作らせる手順を案内しています。新しいプロジェクトは「npx create-video@latest」で作れます。

会社で使う場合の料金は？＋

公式の料金ページ（2026年11月20日確認）では、手作業で動画を作る用途のRemotion for Creatorsが1席あたり月$25、動画を自動で量産する用途のRemotion for Automatorsが1レンダーあたり$0.01（月$100から）です。月$500からのEnterprise Licenseもあります。

Claude Motionとの違いは？＋

Claude MotionはAnthropicが提供する、プロンプトから説明アニメーションを作る機能で、Teamなどの有料プランで使えます。Remotionは自分のパソコンで動かす開発用のツールで、コードを直接編集でき、書き出しの方法も自分で選べます。
