Vrewは安全？どこの国の会社か・インストーラの署名・データの扱いを確認

Vrewは自動字幕で知られるAI動画編集ソフトです。PCにインストールして使うため、提供元がどこの会社か、ソフト自体は安全か、読み込んだ動画や音声がどう扱われるかを確認してから使いたい方も多いはずです。当サイトでは安全か危険かを断定せず、2026年11月22日に公式文書を読み、Mac版のインストーラを取得して署名を確認した結果をまとめました。

Vrewの日本語サイトの会社概要では、運営会社をVoyagerX, Inc.（ボイジャーエックス）とし、事業内容にAI動画編集ソフト「Vrew」とAIスキャンアプリ「vFlat」の開発・運営を挙げています。特定商取引法に基づく表記には、代表者名、ソウルの所在地、事業者登録番号、日本向けの電話番号（050-5370-1478、平日10時〜17時）が記載されています。

返金は、支払い日から14日以内にサービスを一切利用していなければ全額、それ以外は残りの期間分の部分返金と案内しています。口座振替やコンビニ決済の返金は海外送金になり、送金手数料は受け取る側の負担です。

動画・音声データの扱い

個人情報処理方針（2026年10月30日適用）で、動画編集の利用者に関係の大きい項目は次のとおりです。

  • 音声分析（自動字幕）：音声ファイルは字幕ファイルの生成完了後24時間で破棄されます。音声認識にはGoogleとAmazon Web ServicesのAPIを使っています
  • 音声クローニング（AI私の声）：アップロードした音声は1週間保有。自社AIの学習データには使わないと明記しています
  • クラウドに保存したプロジェクト：写真・動画・音声・字幕テキストを含めて、退会後120日間保管されます
  • パーソナライズ：編集体験を最適化するため、プロジェクトの内容と編集履歴をAIで分析します。この目的以外でAIの学習には使わないとしています
  • Vrewエージェント：入力した指示文と作業履歴は退会日から1年保有されます

公式の「データ保護」ページでは、さらに踏み込んで、利用者のクリエイティブコンテンツをAIの学習に使わないこと、利用者の明示的な許可がない限り社内の担当者もコンテンツにアクセスしないことを表明しています。

外部のAI事業者への委託

Vrewの字幕翻訳・音声合成・画像や動画の生成などの機能は、外部のAIサービスを使って提供されています。個人情報処理方針には、国外の委託先として次の事業者が記載されています。

  • テキストの生成・翻訳：OpenAI（ChatGPT API）、Google（Gemini API）、Anthropic（Claude API）、OpenRouter（Vrewエージェント）
  • 画像・動画の生成：Google（Nano Banana・Veo）、BytePlus（Seedream・Seedance）、Kling AI、Stability AI、Replicate（Flux）、fal
  • 音声：ElevenLabs、NAVER、Google、Amazon Web Servicesなど

生成AI機能を使うと、指示文やアップロードした素材がこれらの事業者に送られます。方針では、委託先が受け取った情報をAIモデルの学習に使わないことを条件に契約していると説明しています。国外への移転は拒否できますが、その場合は音声分析やAI生成などの主要機能が使えなくなる可能性があります。

利用前に確認したいこと

  • 入手元：インストーラは公式サイト vrew.ai から取得してください
  • 入力する素材：社外秘の動画や、本人の同意がない人物の音声は、生成AI機能やクラウド保存に使わない運用が安全です
  • 生成物の権利：利用規約では、AI機能で生成した画像ファイルとオーディオファイルは利用者が所有し、商業的にも利用できるとしています。生成物の利用で生じた紛争の責任は利用者が負います
  • 未成年の利用：満14歳未満の利用者がアカウントを作るには、法定代理人の同意が必要です
  • 料金と使い方：プランごとの料金と音声分析の費用はVrewの使い方と料金で解説しています

ほかのAI動画サービスの規約を確認した例として、MiniMax（Hailuo AI）の安全性もあわせてご覧ください。商用利用や著作権の考え方はAI動画の商用利用で解説しています。

よくある質問

Vrewはどこの国の会社が作っていますか？＋

韓国の株式会社ボイジャーエックス（VoyagerX, Inc.）です。会社概要と特定商取引法に基づく表記では、所在地を大韓民国ソウル特別市瑞草区、代表者をナム・セドン氏としています。日本向けの問い合わせ電話番号（050番号）も表記されています（2026年11月22日確認）。

Vrewのインストーラにウイルスは入っていませんか？＋

当サイトでウイルス検査をしたわけではないため、断定はできません。確認できた事実として、公式サイトから取得したMac版インストーラ（Vrew 4.9.1）のアプリは「Developer ID Application: VoyagerX, Inc.」の署名つきで、AppleのGatekeeperの検査で「Notarized Developer ID（公証済み）」と判定されました（2026年11月22日確認）。ダウンロードは公式サイト vrew.ai から行ってください。

Vrewに読み込んだ動画や音声はAIの学習に使われますか？＋

公式の「データ保護」ページでは、利用者のクリエイティブコンテンツをAIの学習に使うことはないと明記しています。個人情報処理方針（2026年10月30日適用）でも、音声クローニング用の音声データを自社AIの学習に使わないこと、外部の生成AI事業者とは学習に使わないことを条件に委託契約を結んでいることが記載されています。

音声分析（自動字幕）のためにアップロードした音声はいつ消えますか？＋

個人情報処理方針では、音声分析のための音声ファイルの保有期間を「音声分析及び字幕ファイルの生成完了後24時間」としています。クラウドに保存したプロジェクトファイルは、退会後120日間保管され、チャット相談などで依頼すればすぐに削除すると記載されています。

Vrewで作った動画を仕事で使っても問題ありませんか？＋

利用規約では、アップロードしたコンテンツの権利は利用者に残り、AI機能で生成した画像ファイルとオーディオファイルは利用者が所有し、商業的にも利用できるとしています。ただし、素材の権利処理と、生成物の利用で生じた紛争の責任は利用者が負います。会社で使う場合は、準拠法が韓国法である点も含めて社内の規程に沿って判断してください。
