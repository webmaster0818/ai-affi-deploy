MagicAnimateとは？使い方・必要なファイル・ライセンスと現在の状況

MagicAnimateは、写真1枚の人物を、別の動画の動きに合わせて動かす研究用のモデルです。シンガポール国立大学（Show Lab）とByteDanceの研究チームが2023年11月に発表し、CVPR 2024に採択されました。2026年11月21日に公式リポジトリとHugging Faceを確認し、必要なファイルと容量、動かし方、デモの稼働状況、ライセンスの注意点をまとめました。

MagicAnimateの概要

  • 写真＋動きの見本で動画を作る：人物の写真（参照画像）と、動きを表すDensePose動画を入れると、写真の人物がその動きをする動画を作ります
  • 見た目を保ったまま動かす：服や顔などの見た目を保つ部品（appearance encoder）と、フレーム間のちらつきを抑える部品を組み合わせています
  • 無料・ローカルで動かす：BSD 3-Clauseで公開。WebサービスではなくGPUのあるパソコンで使います
  • 更新は2023年12月が中心：推論コードとデモの公開（2023年12月4日）以降、2025年8月にデモ用ファイルが修正されたのみです（2026年11月21日確認）
  • 公式デモは停止中：Hugging Face Spacesのデモは2026年11月21日時点でエラー状態でした

必要なファイルと容量

READMEの「Getting Started」に書かれた配置と、Hugging Face（zcxu-eric/MagicAnimate）のファイル一覧を、当サイトで1つの表にまとめました。容量はHugging FaceのAPIで取得した値です。

ファイル入手先容量役割
appearance_encoderzcxu-eric/MagicAnimate約3.43GB参照画像の見た目（顔・服）を保つ
densepose_controlnetzcxu-eric/MagicAnimate約1.45GBDensePose動画の動きに沿わせる
temporal_attentionzcxu-eric/MagicAnimate約5.11GBフレーム間のつながりを保つ
Stable Diffusion 1.5別途入手（下記の注意を参照）—画像生成の土台
sd-vae-ft-msestabilityai/sd-vae-ft-mse—画像の復元（VAE）

※MagicAnimate本体の3ファイルだけで合計約9.98GBです（当サイト計算）。Stable Diffusion 1.5とVAEは別に必要です。

注意点として、READMEのStable Diffusion 1.5へのリンク（runwayml/stable-diffusion-v1-5）は、2026年11月21日に確認した時点でHugging Faceのページが開けませんでした（HTTP 401）。同じモデルは、Hugging Face上の「stable-diffusion-v1-5/stable-diffusion-v1-5」で公開されています（2024年8月作成・CreativeML OpenRAIL-M）。READMEの手順どおりにダウンロードできない場合は、入手先の違いに注意してください。

使い方（公式READMEの手順）

  1. 環境を用意する：Python 3.8以上、CUDA 11.3以上、ffmpegが必要です。condaの場合は environment.yaml、pipの場合は requirements.txt で必要なライブラリを入れます
  2. モデルを配置する：上の表のファイルを pretrained_models フォルダに置きます。READMEでは git lfs でのダウンロードを推奨しています
  3. 生成する：GPU 1枚なら scripts/animate.sh、複数枚なら scripts/animate_dist.sh を実行します
  4. 画面で操作する場合：python3 -m demo.gradio_animate でローカルのデモ画面を起動し、ブラウザで写真と動きの動画を指定します

公式の設定ファイル（configs/prompts/animation.yaml）では、解像度512、1回に処理する長さ16フレーム、ステップ数25が初期値です。長い動画は、短い区間を重ねてつなぐ方式で作ります。

動きの入力はDensePose形式

MagicAnimateの動きの見本は、普通の撮影動画ではなく、人体の部位ごとに色分けしたDensePose形式の動画です。公式の例（inputs/applications/driving/densepose/）には、走る・踊るなどのDensePose動画が入っています。

自分の動画の動きを使うには、先にDensePose動画へ変換する必要がありますが、その手順はREADMEに書かれていません。GitHubのIssueでは、DensePoseで検索すると42件が見つかり（2026年11月21日 当サイト確認）、変換方法やちらつき、OpenPoseで代用できるかといった質問が並んでいます。手軽に試したい人にとっては、この変換の手間が最初の壁になります。

ライセンスと利用時の注意

  • MagicAnimate本体：BSD 3-Clause（GitHubリポジトリ・Hugging Faceのモデルカード）
  • Stable Diffusion 1.5：CreativeML OpenRAIL-M。有害な用途などの利用制限が定められています
  • sd-vae-ft-mse：MIT（Hugging Faceのモデルカード）
  • 写真の人物の権利：実在の人物の写真を動かす場合は、本人の同意や肖像の扱いに注意が必要です。生成AIと著作権の考え方はAI動画の商用利用と著作権で解説しています

ほかの「写真を動かす」モデルとの違い

MagicAnimateは2023年の研究モデルで、解像度は512が基本です。同じ「写真の人物に動画の動きをまねさせる」用途では、Alibabaが公開したWan-Animate（動きの転写と人物の置き換えに対応）があり、仕様と費用はWan Animateの解説にまとめています。仕組みの近いモデルとしては、画像モデルに動きを足すAnimateDiffもあります。写真1枚と音声から話す動画を作るならOmniHuman、アプリで手軽に試すならViggle AIが選択肢です。

よくある質問

MagicAnimateは無料で使えますか？＋

無料です。公式リポジトリ（magic-research/magic-animate）とHugging Faceのモデルは、BSD 3-Clauseライセンスで公開されています。自分のパソコンのGPUで動かすため、利用料はかかりません。

ブラウザで試せるデモはありますか？＋

READMEにはHugging Face Spacesのオンラインデモ（zcxu-eric/magicanimate）が案内されていますが、2026年11月21日に当サイトが確認した時点では、このデモはエラー状態（RUNTIME_ERROR）で動いていませんでした。

普通のダンス動画をそのまま動きの見本に使えますか？＋

公式の例では、動きの入力にDensePose形式の動画（人体の部位を色分けした動画）を使っています。READMEには普通の動画からDensePose動画を作る手順は書かれておらず、GitHubのIssueでも変換方法についての質問が複数寄せられています。

商用利用はできますか？＋

MagicAnimateのコードとモデルはBSD 3-Clauseです。ただし、土台として使うStable Diffusion 1.5はCreativeML OpenRAIL-Mという別のライセンスで、用途の制限が定められています。商用で使う場合は、組み合わせるモデルすべてのライセンスを確認してください。

今から使うなら、ほかの選択肢はありますか？＋

MagicAnimateの更新は2023年12月の公開が中心で、その後の主な変更はデモ用ファイルの修正のみです。写真の人物に動画の動きをまねさせる用途では、2025年以降に公開されたWan-Animateなどの新しいモデルもあります。
