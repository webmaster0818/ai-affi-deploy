Wan 3.0とは？30秒の動画生成・API料金・Wan2.xとの違い

Wan 3.0は、Alibabaの動画生成AI「Wan」シリーズの最新世代です。1回の生成で最長30秒の動画を作れ、文章・画像・音声・動画に加えて、PDFやスライドなどの文書も入力に使えます。当サイトでは2026年11月22日にAlibaba Cloudの公式ブログ・料金表・利用ガイドを確認し、できること、料金、使える場所を整理しました。

Wan 3.0の概要

  • 最長30秒を1回で生成：前世代のWan2.7（最大15秒）の2倍です。出力は30fps
  • 文書から動画を作れる：doc・xls・ppt・pdf・txt・key・pages・numbers・md、またはWebページのリンクを1件まで参照できます
  • 音声つきで出力：セリフ・BGM・効果音を動画と一緒に生成します
  • APIは1秒$0.05から：Alibaba Cloud Model Studio（シンガポール地域）の標準版・480Pの定価です
  • 重みは公開されていません：Wan2.1・Wan2.2と違い、自分のPCでは動かせません

公開までの経緯

Alibaba Cloudの公式ブログ（Alizilaの転載）によると、Wan 3.0は2026年8月7日にベータ版として公開され、Model StudioとQwen Cloudで試用を申し込む形で始まりました。8月13日の公式ブログでは、Alibaba Cloud Model Studioで利用できると案内し、API料金も公表しています。

Wanシリーズは2023年7月に始まり、公式ブログでは「Wan1.0からWan3.0までに8回の改良を重ねた」と説明しています。このうちWan2.1（GitHubリポジトリ作成 2025年2月25日）とWan2.2（同 2025年7月28日）は、重みが一般に公開されています。

API料金と1本あたりの費用

Model Studioの料金表（2026年11月21日更新）では、生成した動画の秒数で課金されます。動画を参照したり編集したりする場合は、入力した動画の秒数も課金対象です。失敗した生成には料金がかかりません。

wan3.0-video 1080P$0.20$2.00$6.00
wan3.0-video-prime 480P$0.068$0.68$2.04
wan3.0-video-prime 720P$0.14$1.40$4.20

※1秒あたりはModel Studio料金表の定価（2026年11月22日確認）。10秒・30秒は当サイトの計算です。標準版には「期間限定30%オフ」の表示がありますが、割引後の金額と期間は料金表の本文から確認できなかったため、定価で計算しています。

  • 動画を編集する場合の例：15秒の動画を参照して1080Pで15秒に作り直すと、課金対象は入力15秒＋出力15秒＝30秒で、標準版なら$6.00です（当サイトによる計算）
  • 無料枠：シンガポール地域の標準版のみ、入力と出力の合計30秒分（90日間）。Primeとほかの地域にはありません
  • 東京リージョンもあります：料金表には日本（東京）地域の行があり、標準版の定価は480Pで1秒$0.041256、1080Pで$0.165025、Primeは1080Pで$0.254399です（北京・フランクフルト・バージニア・香港と同額）。ただし無料枠の対象外です

APIを使わずに試す方法として、Wan 3.0は動画制作サービスのPikaでも選べます。Pikaでの消費クレジットは新しいPikaの料金と使い方で整理しています。

Wan2.xとの違い

項目Wan2.1／Wan2.2Wan2.7Wan 3.0
重みの公開公開（GitHub・Hugging Face）公式リポジトリなし公式リポジトリなし
1回の最大の長さ—15秒30秒
文書の入力——対応（1件まで）
動画の編集—導入引き継ぎ

※重みの公開状況は、2026年11月22日に公式GitHub（Wan-Video：Wan2.1・Wan2.2・Wan-Animate-2・Wan-Dancer・Wan-skills・diffusers）とHugging Face（Wan-AI）のモデル一覧を確認した結果です。Wan2.7の最大15秒と動画編集の導入は、Wan 3.0の公式ブログの記載によります。「—」は当サイトで比較できる公式の記載を確認していない項目です。

手元のGPUで動かしたい場合は、重みが公開されているWan2.2系が対象になります。必要なGPUメモリは動画生成AIに必要なPCスペック、写真の人物を動かすWan2.2系のモデルはWan Animateとはで解説しています。

公式が挙げている課題と注意点

  • 音声と画面内の文字：公式ブログでは、音声の質感と、画面に表示する文字の正確さはまだ改善の途中だとしています
  • 地域をそろえる：モデル・エンドポイント・APIキーは同じ地域のものを使う必要があり、地域をまたいだ呼び出しは失敗します
  • 文書・Webページの参照：ログインが必要なページは読み込めません。社外秘の資料を入力する場合は、社内の規程に沿って判断してください
  • 人物の参照：本人の許可のない写真や動画を参照素材にすると、肖像権やなりすましの問題につながります。商用利用の考え方はAI動画の商用利用をご覧ください

ほかのモデルの料金と比べる場合は、同じく1秒単位で課金されるSeedance 2.5やKling 4.0の解説が参考になります。同じAlibabaの動画生成AIで、15秒以内なら1080Pの単価が安いHappyHorseもあります。ご利用前に、公式サイトにて最新の料金をご確認ください。

よくある質問

Wan 3.0はいつ公開されましたか？＋

Alibaba Cloudの公式ブログによると、2026年8月7日にベータ版の提供が始まり、Model StudioとQwen Cloudで利用を申し込める形でした。8月13日の公式ブログでは、Alibaba Cloud Model Studioで利用できると案内しています。

Wan 3.0は無料で使えますか？＋

Alibaba Cloud Model Studioのシンガポール地域では、標準版のwan3.0-videoに合計30秒分の無料枠があります（Model Studioの有効化日・モデル公開日・申請承認日のいずれか遅い日から90日間）。上位版のwan3.0-video-primeと、シンガポール以外の地域には無料枠がありません（2026年11月22日確認）。

Wan 3.0を自分のPCで動かせますか？＋

動かせません。Wan2.1とWan2.2は重みが公開されましたが、2026年11月22日に公式のGitHub（Wan-Video）とHugging Face（Wan-AI）を確認したところ、Wan 3.0のリポジトリ・モデルはありませんでした。利用はAlibaba CloudのAPIか、Wan 3.0を組み込んだ他社サービスを通す形になります。

30秒の動画を1本作るといくらかかりますか？＋

シンガポール地域の定価（標準版）は、480Pで1秒$0.05、720Pで$0.10、1080Pで$0.20です。30秒なら480Pが$1.50、720Pが$3.00、1080Pが$6.00になります（当サイトによる計算）。Prime版は1080Pで1秒$0.28のため、30秒で$8.40です。

Wan 3.0とWan2.xは何が違いますか？＋

公式ブログでは、1回で生成できる長さが前世代のWan2.7の最大15秒から30秒に延びたこと、PDFやスライドなどの文書を入力に使えるようになったこと、人物の顔や参照素材の再現性を高めたことを挙げています。Wan2.7で導入された動画編集機能も引き継いでいます。
