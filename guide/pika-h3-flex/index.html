Pika H3 Flexとは？無料公開のモデルの料金・必要なGPU・日本での利用条件

AI動画のPikaは2026年10月29日、新しい動画生成モデル「Pika H3 Flex」を公開しました。MiniMax H3をPikaが追加学習したモデルで、最大12個の参照ファイルを読み込み、音声付きの動画を作ります。重み（モデル本体）が無料で公開されている点が大きな特徴です。APIの料金、自分のGPUで動かすのに必要な環境、日本で使うときのライセンス条件を公式情報で整理します。

要点

  • 2026年10月29日公開：MiniMax H3をPikaが追加学習し、生成の工程を50ステップから6ステップに減らした高速版
  • 参照は最大12個：画像9枚・動画3本・音声3本まで（合計12個）。キャラクター・背景・動きを別々の素材から指定できます
  • 音声付き・最大15秒：5〜15秒の動画をステレオ音声付きで生成。APIではセリフ・BGM・効果音・フォーリー・環境音の5トラックに分けて受け取れます
  • 重みを無料公開：Hugging FaceとGitHubで公開。ただし公式の動作確認はH100（80GB）クラスのGPU
  • APIは1秒$0.01から：テキストから動画の480pの場合。4Kは1秒$0.08。別に月$10の会費がかかります
  • pika.artには11月2日に追加予定：制作画面での消費クレジットはまだ公表されていません

Pika H3 Flexで何ができるか

Pika H3 Flexは、MiniMaxの動画生成モデル「MiniMax H3」をもとに、Pikaが画質と操作性を高める追加学習をしたモデルです。公式ブログは、最初の1本を作ったあとに何度も直す使い方を想定し、生成の速さと直しやすさを重視したと説明しています。公式ブログとHugging Faceのモデルページに書かれている主な機能は次のとおりです。

  • 参照から動画：スケッチ、キャラクターの設定画、商品写真、ムードボード、声のサンプル、振り付けの動画などを組み合わせて1本の動画にします。「この画像からキャラクター、この画像から背景、この動画から動き」のように役割を指示できます
  • 最初と最後のコマの指定：開始画像・終了画像のどちらか、または両方を指定して、その間をつなぐ動画を作れます
  • カメラワークとカット割り：俯瞰からのクレーンダウン、素早いパン、被写体を回り込む動きなどを1本の中で秒単位で指示できます。カットの切り替えやセリフを含む構成も作れます
  • 部分的な作り直し：演技とタイミングを保ったまま、衣装・小道具・背景だけを差し替える編集に対応します
  • 5つの音声トラック：PikaのAPIでは、セリフ・BGM・効果音・フォーリー（足音などの動作音）・環境音を別々のファイルで受け取れます。BGMだけ下げる、といった調整が編集ソフト側でできます

速さについて公式は、768p・15秒・音声付きの動画を「最短7秒の計算時間」で作れるとしています（注記付きの条件での数値です）。また、公開時点でDesignArenaのテキストから動画のランキングで「オープンウェイトのモデルで1位、全体で7位」だったとしていますが、これはPika自身の発表です。

APIの料金

PikaのAPIは「Pika API Club」という会員制で、月$10の会費がかかり、初月は$10分のクレジットが付きます。そのうえで、使った分だけ支払う従量課金です。公式の料金ページ（dev.pika.art/pricing、2026年10月30日確認）に書かれたPika H3 Flexの料金は次のとおりです。

解像度テキスト／画像から動画（1秒）参照から動画（1秒）10秒の例（テキストから）
480p$0.01$0.03$0.10
768p$0.02$0.06$0.20
1080p$0.035$0.075$0.35
2K$0.04$0.08$0.40
4K$0.08$0.10$0.80

※2026年10月30日にdev.pika.art/pricingで確認。10秒の例は当サイトによる単純計算です。参照から動画で参照用の動画を入れる場合は、入力した動画にも同じ解像度の1秒あたり料金（480pで$0.03など）がかかると書かれています。音声トラックの分割は1秒$0.001。下書き動画を高解像度化する場合は「下書き分の料金を差し引く」と表示されています。価格は変更される場合があります。

参照を使う生成はテキストから動画の約1.25〜3倍の料金です。構図や動きを詰める段階は480pで回し、決まったものだけ高解像度にすると費用を抑えられます。公式ブログも「768pで試して、気に入ったものを1080p・2K・4Kに仕上げる」という使い方を勧めています。

自分のGPUで動かすには

重みはHugging Face（Pika-Labs/Pika-H3-Flex）、推論コードはGitHub（Pika-Labs/Pika-H3-Flex）で公開されています。ComfyUIの公式チュートリアルとワークフロー、Hugging FaceのDiffusersにも対応しています。ただし、必要な環境はかなり大きめです。公式の動作確認資料（docs/hardware.md）の内容をまとめます。

  • 動作確認済みのGPU：NVIDIA H100（80GB）。1回の生成に1枚のGPUを使い、複数のGPUに分けて処理する機能はありません。H200・B300は未検証
  • GPUメモリ：480p・5秒の生成で約66〜69GB。768p・15秒はH100でも足りず、CPUオフロード（GPU約29〜32GB、メインメモリ約94GB）が必要でした。公式は「これは最低要件ではない」とし、余裕を持たせるよう書いています
  • ストレージ：ベースモデル（MiniMax H3の部品）が約211GB、Pikaのアダプター2種で約5.5GB。ほかに依存ソフトとダウンロード用の空きが必要
  • ソフト：Python 3.12と対応するNVIDIAドライバー。pip・Conda・Dockerでのインストール手順あり

家庭用のGPU（VRAM 24GB以下など）で動くかは公式に書かれていません。公開されている数値を見る限り、手元のPCで気軽に試すモデルではなく、クラウドのGPUを借りるか、まずAPIで試すのが現実的です。Pika自身もAPIの料金ページで「1秒$0.01から」と案内しています。

日本で使うときのライセンス条件

公開された重みは「MiniMax H3 Community License Agreement」で配布されています（Pikaのアダプターは MiniMax H3 の派生物という扱い）。オープンウェイトですが、自由に使える一般的なオープンソースのライセンスとは違い、条件が付いています。主な点は次のとおりです。

  • 使える地域：「全世界から、欧州連合・英国・韓国・米国を除いた地域」。日本は使える地域に入っています。除外地域での利用や生成物の利用は、このライセンスでは認められていません
  • 商用利用：可能。ただし、Pika H3 Flex（MiniMax H3）を使った商用の製品・サービスでは、画面に「MiniMax H3」と目立つように表示する必要があります。年間売上が2,000万ドルを超える事業は、MiniMaxから事前に書面で許可を得る必要があります
  • 生成物：MiniMaxは生成物の権利を主張しないと書かれています。生成物の扱いと責任は利用者側にあります
  • 禁止されていること：生成物を、MiniMax H3系以外のAIモデルの改良に使うこと。利用規約（Acceptable Use Policy）に反する使い方
  • 他の人に使わせる場合：自分のサービスで第三者に生成させるなら、同等の利用制限を利用者に課し、不正な使い方を防ぐ対策を取ることが求められています

※2026年10月30日にHugging Faceに置かれたライセンス本文で確認。上は要点の抜粋です。実際に事業で使う前には原文を確認してください。PikaのAPIや制作画面で使う場合は、Pikaの利用規約も適用されます。

AI動画を広告や収益化に使うときの一般的な注意点はAI動画の商用利用の注意点にまとめています。

日本語には対応している？

公式のプロンプトガイドは、場面の説明は英語で書き、セリフと画面内の文字は話させたい言語のまま書くよう案内しています。セリフには言語名のタグを付ける書き方で、例として英語と中国語のセリフが載っています。

ただし同じガイドに、言語タグは「話させたい言語を指定するもので、動作を確認した対応言語の一覧ではない」と書かれています。日本語のセリフが自然に出るかは公式には保証されていません。日本語ナレーションが必須の動画なら、まず480pの短い動画で発音と口の動きを確かめるか、日本語の音声に強いツールと組み合わせてください。日本語対応の状況は日本語に強いAI動画ツールで比較しています。

他の新モデルとの違い

同じ時期に出たモデルでは、Kling 4.0が1回最大30秒、Vidu Q4が画像15枚・音声3本の参照で最大16秒・4Kを打ち出しています。どちらも各社のサービス上で使うモデルです。

Pika H3 Flexは、重みが公開されていて自前の環境に組み込めること、APIの最低料金が1秒$0.01と安いこと、音声を5トラックに分けて受け取れることが違いです。一方で、一般の利用者向けの制作画面での提供は11月2日からで、そこでの料金はまだわかりません。ツール全体の比較はAI動画ツールおすすめ比較を参照してください。

よくある質問

Pika H3 Flexは無料で使えますか？＋

モデルの重みと推論コードはHugging FaceとGitHubで無料公開されているので、自分のGPUで動かすなら利用料はかかりません。ただし公式が動作を確認しているのはH100（80GB）クラスのGPUです。PikaのAPIで使う場合は、月$10の会費（初月は$10分のクレジット付き）に加えて、生成した秒数ぶんの従量課金がかかります。pika.artの制作画面には2026年11月2日に追加される予定で、そこでの消費クレジットはまだ公表されていません。

家庭用のGPUで動きますか？＋

公式の動作確認はH100 80GBのみで、480p・5秒の生成でもGPUメモリを約66〜69GB使ったと書かれています。768p・15秒はH100でもメモリが足りず、CPUオフロード（GPU約29〜32GB＋メインメモリ約94GB）が必要でした。ほかにストレージが約217GB要ります。家庭用GPUでの動作は公式に書かれていません。

日本から使っても大丈夫ですか？＋

重みのライセンス（MiniMax H3 Community License）は、使える地域を「全世界から欧州連合・英国・韓国・米国を除いた地域」と定めており、日本は使える地域に入っています。商用サービスで使う場合は画面に「MiniMax H3」と表示すること、年間売上が2,000万ドルを超える事業は事前の許可が必要なことなどの条件があります。PikaのAPI経由で使う場合はPikaの利用規約も適用されます。

日本語のセリフを話せますか？＋

公式のプロンプトガイドは「場面の説明は英語で書き、セリフと画面内の文字は話させたい言語で書く」と案内しています。ただし、セリフに付ける言語タグは「対応言語の一覧ではない」とも書かれており、日本語の音声が自然に出るかは保証されていません。短い動画で試して確かめてください。

作った動画を商用利用できますか？＋

ライセンスには「MiniMaxは生成物の権利を主張しない」と書かれています。一方で、生成物を別のAIモデルの学習・改良に使うことは禁止されています。Pika H3 Flexを組み込んだ商用の製品・サービスを作る場合は、画面への「MiniMax H3」の表示が必要です。PikaのAPIやアプリで作った動画は、Pikaの利用規約もあわせて確認してください。
