Gemini Live Avatarとは？話すアバターの料金・使える条件・顔写真の要件

Gemini Live Avatarは、Googleの会話モデル「Gemini 3.8 Live」の音声に合わせて、口を動かして話すアバターの映像をほぼリアルタイムで作る機能です。当サイトでは2026年11月25日にGoogleの公式ブログ・Google Cloudの文書・料金表を確認し、使える条件と料金の目安を整理しました。

Gemini Live Avatarの概要

  • 会話しながら映像で応答：利用者の声やカメラ映像を受け取り、アバターが口の動きを合わせて話します
  • 企業向け：Google Cloudの「Gemini Enterprise Agent Platform」で提供。2026年9月24日に一般提供が始まりました
  • 97言語・日本語対応：会話の途中で言語を切り替えても、口の動きと表情が合わせて変わります
  • 独自アバターは許可制：用意されたアバターから選ぶのが基本で、顔写真から作る独自アバターは許可を得た企業のみ
  • SynthIDの透かし入り：生成された音声と映像には、見えない電子透かしが入ります

HeyGenやSynthesiaのように台本からアバター動画を書き出すツールとは違い、Live Avatarは「その場で会話する」窓口用の機能です。動画として書き出すアバター作成ツールはアバター動画AIツールの比較で整理しています。

Agent Platformの料金表（Gemini 3.8 Live API・グローバル以外の地域）では、トークン数で課金されます。アバターの映像は、アバターが話している時間だけ課金され、聞いている時間は課金されません。

  • 会話が長いほど1回あたりが高くなる：料金表の注記では、1往復（ターン）ごとに、それまでの会話の内容もあわせて再処理・課金されるとしています（設定した上限まで）。上の表は出力だけの目安です
  • 処理枠を確保する契約もある：大量に使う場合は、Google Cloudの営業担当を通じてProvisioned Throughput（処理能力の確保）を申し込む形が案内されています

独自アバター用の写真の要件

独自アバターは許可制ですが、「Configure live avatars」には参照写真の条件が公開されています。

  • 形式：PNGを推奨（背景を透過にすると、明るい画面・暗い画面のどちらでも枠が見えません）
  • 大きさ：縦向き704×1280ピクセル以上、横向き1280×704ピクセル以上。比率は9:16か16:9
  • 構図：頭と肩が画面の60%以上を占める胸から上の写真。腕・手・マイクなどの持ち物は入れない
  • 背景と向き：ほかの人が写っていない無地の背景で、正面を向き、目線はカメラ
  • 表情：笑顔や歯を見せない、落ち着いた無表情
  • 使えない写真：未成年・著名人・不快な内容の写真

顔や声のデータを使うための同意と権利は、利用する企業の側で確保する必要があります。本人の許可のない写真を使うと、肖像権やなりすましの問題につながります。考え方はAI動画の商用利用をご覧ください。生成された映像に入る透かしは、SynthID Detectorで確認できます。

よくある質問

Gemini Live Avatarは個人でも使えますか？＋

Googleの公式ブログは、企業向けの機能として案内しています。利用はGoogle Cloudの「Gemini Enterprise Agent Platform」の管理画面か、Gemini Live APIを通す形です。Geminiアプリで一般の利用者が使える機能としての案内は、当サイトでは確認できていません（2026年11月25日確認）。

Gemini Live Avatarはいつから使えますか？＋

Google Cloud Next 2026でプレビューが公開され、2026年9月24日に一般提供（GA）が始まりました。モデルの文書では、Gemini 3.8 Liveのリリース日を2026年9月24日、サポート終了日を2027年9月25日以降としています。

日本語で会話できますか？＋

できます。Gemini 3.8 Liveは97言語に対応し、言語と音声の設定ページの対応言語に「Japanese (Japan)／ja-JP」が含まれています。会話の途中で言語が変わっても、口の動きを合わせて切り替えると公式ブログは説明しています。

自分や社長の顔でアバターを作れますか？＋

顔写真1枚から独自のアバターを作る機能はありますが、許可を得た一部の企業（allowlist）に限られます。利用するにはGoogle Cloudの担当チームへの申請が必要で、顔や声のデータの処理に必要な同意と権利は利用者側で確保するよう定められています。

料金はいくらかかりますか？＋

Agent Platformの料金表では、アバターの映像出力は100万トークンあたり$1.00で、映像1秒は6,192トークンと換算されます。アバターが話している時間だけ課金され、聞いている時間は課金されません。話した1分あたりの映像と音声の出力は約$0.39です（当サイトによる計算・入力やこれまでの会話の再処理分は別）。
