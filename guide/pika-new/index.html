新しいPikaとは？料金プラン・無料でできること・旧Pikaからの変更点

AI動画生成の「Pika」が2026年9月17日に全面刷新され、動画・画像・音声を1か所で作れる制作プラットフォームになりました。自社モデルのPika 2.5に加えてSeedance 2.5やWan 3.0など他社モデルも選べるようになり、料金体系も一新。Freeプランは月次クレジットが0になり、生成にはクレジットパックの購入か有料プランが必要です。この記事では、Pika公式ブログと料金ページの記載をもとに、何が変わったのか・いくらかかるのか・旧Pikaユーザーはどうなるのかを整理します。

新しいPikaとは（公式発表の要点）

Pikaは2026年9月17日、公式ブログ「Welcome to the New Pika」で新しいPikaを発表しました。公式は新Pikaを「クリエイターのための、クリエイターによるAIクリエイティブプラットフォーム」と位置づけ、動画・画像・音声の制作を1か所にまとめ、主要な生成モデルの上に用途別の「アプリ」を載せた構成だと説明しています。

公式発表から読み取れる変更点は次の通りです。

  • 動画専用ツールから、動画・画像・音声の総合プラットフォームへ：ローンチ時点で25以上のアプリを提供
  • 他社モデルを含むマルチモデル化：Seedance、GPT Image、MiniMax H3、Pika自社モデルなどをアプリが自動で使い分け、自分でモデルを指定することも可能
  • 料金体系の一新：プランの違いは「クレジット量と同時生成数だけ」。全ユーザーが全モデル・全アプリを利用可能
  • 旧Pikaは old.pika.art へ：pika.art が新Pikaになり、旧インターフェースは「あと数週間」残した後に終了予定

クレジットパック（買い切りの追加クレジット）

サブスクリプションとは別に、買い切りのクレジットパックが用意されています。レートは全プラン共通で1ドルあたり60クレジットで、25ドル（1,500クレジット）から1,000ドル（66,000クレジット・10%増量）まで選べます。Freeプランのままでも購入でき、購入してもサブスクリプションは始まりません。

  • 有効期限：パックで購入したクレジットは繰り越され、購入から365日で失効
  • プラン付属のクレジット：請求期間ごとにリセットされ、繰り越しなし
  • 使える場所：パックのクレジットは pika.art の制作画面専用。公式は「API・MCP・iOSアプリ・old.pika.art では使えない」と明記

無料でできること：Freeプランは「月次クレジット0」

「Pika 無料」で調べている方がいちばん注意したいのがここです。公式料金ページでは、Freeプランは「0 credits / month · packs only」と記載されています。アカウント登録は無料で、全モデルにアクセスでき透かしも入りませんが、毎月自動で付与されるクレジットはありません。実際に生成するには、クレジットパックを購入するか有料プランに加入する必要があります。

日本語の解説記事には、毎月の無料クレジットが付く前提で書かれたものがまだ多く残っています。新Pikaの料金ページの記載とは異なるため、情報の日付を確認してください。「まず無料で試してから決めたい」場合の選択肢は無料で使えるAI動画ツールでまとめています。

ここから単純計算すると、Starter（月10ドル）でSeedance 2.5の5秒・720p動画を作れるのは月7本ほどです。クレジットパックで同じ動画を作る場合は、122クレジット÷60＝1本あたり約2ドルになります（当サイトによる計算）。モデルによって消費量に4倍近い差があるので、ラフはWan 3.0で作り、仕上げだけSeedance 2.5を使う、といった使い分けでクレジットを節約できます。

使えるモデルとアプリ

公式サイトのモデル一覧（2026年10月4日閲覧）に掲載されているモデルは次の通りです。

  • 動画：Seedance 2.5 / MiniMax H3 / Wan 3.0 / Google Omni Flash / Pika 2.5 / Pikaframes
  • 画像：GPT Image 2.5 / Nano Banana / Seedream 5 / Seedream 4 / Grok Imagine
  • 音声・読み上げ：Pika Speech / ElevenLabs Multilingual v2 / ElevenLabs Turbo v2.5
  • 音楽・効果音：Pika Music / Pika Soundtrack / Pika SFX / MiniMax Music 3.0

公式ブログは「モデル名は必要なときだけ表に出し、不要なときは見えなくする」という方針を説明しています。アプリが作業に合ったモデルを自動で選び、こだわりたい人は自分で指定する、という設計です。ブログで紹介されている主なアプリは次の4つです。

  • Video Studio：キャラクター・商品・背景・スタイルを最大50個まで登録し、プロンプト内で@メンションして使う。短いクリップから、最長30秒・音声付きのマルチショット動画まで作成
  • Relight Media：写真や動画の被写体・構図・動きを保ったまま、光と影を作り直す
  • Product Shot：スマホで撮った商品写真を、ライティング済みのキャンペーン用画像に変換
  • Camera Director：既存のシーンを保ったまま、超ワイドからクローズアップまで別アングルで撮り直す

また公式は「現時点で、PikaでのSeedance生成は他の制作プラットフォームの半額」と主張しています。ただしこれはPika自身による発表時点（2026年9月17日）の説明で、当サイトが他社と比較検証した結果ではありません。公式も「明日どうなるかは分からない」と断っているため、契約前に各社の料金ページを見比べるのが確実です。

旧Pikaユーザーはどうなる？

公式ブログは、既存ユーザー向けに次の4点を案内しています。

  • アカウントはそのまま：同じログインで利用可能。再登録・再契約・手動の移行は不要
  • サブスクリプションは引き継ぎ：「同じプラン・同じ価格」。移行期間中、pika.art が新Pika、旧インターフェースは old.pika.art で「あと数週間」提供され、終了前に告知
  • ライブラリも移行：有料会員の過去の生成物は「OG Pika」プロジェクトに表示
  • 初回ログイン時にツアー：ライブラリ・アプリ・作例の場所を案内

旧インターフェースの具体的な終了日は、本記事執筆時点（2026年10月4日）では公表されていません。旧画面で作業中の素材がある場合は、告知を待たずに早めに書き出しておくと安心です。

日本語対応・日本からの利用

  • 日本語UI・日本語プロンプト：公式ブログと料金ページには、対応言語についての記載がありません。日本語での使い勝手は、実際にログインして確認するのが確実です
  • 日本語の読み上げ：モデル一覧に多言語対応の音声モデル（ElevenLabs Multilingual v2）が含まれていますが、新Pika上での日本語品質について公式の説明はありません
  • 支払い：料金は米ドル建てです。円での請求額は為替とカード会社のレートで変わります

日本語ナレーションやテロップを重視した選び方は日本語対応のAI動画ツールでまとめています。

新しいPikaが向いている人・向いていない人

  • 向いている：Seedance・Wan・Pikaなど複数の動画モデルを1つの契約で使い分けたい人。動画に加えて画像・音楽・効果音までまとめて作りたい人
  • 向いている：毎月は使わないので、必要なときだけクレジットパックで買い足したい人（パックは365日有効）
  • 向いていない：完全無料で試したい人（Freeプランは月次クレジット0）
  • 向いていない：ナレーション付きの解説動画を量産したい人。この用途はFlikiやPictoryのほうが合っています

同時期の動きとして、Klingも次世代モデルを発表しています（Kling 4.0とは）。Sora終了後の乗り換え先の全体像はSora終了と代替ツール、ツール選び全体はAI動画ツールおすすめ比較で整理しています。

利用前の注意点

  • 返金なし：公式FAQによると、解約はいつでも可能で請求期間の終わりまで利用できますが、支払いは返金不可です
  • プラン変更：アップグレードは即時適用、ダウングレードは次の請求期間の開始時に適用（それまでは取り消し可能）
  • 商用利用：商用ライセンスはCreator以上。Starterで作った動画を仕事に使う前に、必ず利用規約を確認してください（AI動画の商用利用の注意点）
  • クレジット消費はモデル次第：同じ5秒の動画でも、モデルによって33〜122クレジットと差があります。解像度や長さを上げるとさらに増える可能性があります

まとめ

新しいPikaは、動画生成ツールから「動画・画像・音声を1か所で作れる制作プラットフォーム」へと作り替えられました。Seedance 2.5やWan 3.0など他社モデルも同じクレジットで使えるのが最大の変化です。一方で、Freeプランは月次クレジットが0になり、無料で作り続けることはできません。料金はStarterが月10ドル（900クレジット）、商用ライセンスが付くのはCreator（月35ドル）以上。旧Pikaのアカウントと契約はそのまま引き継がれますが、旧インターフェースは近く終了予定です。続報があれば本記事を更新します。

よくある質問

新しいPikaは無料で使えますか？＋

アカウント登録と全モデルへのアクセスは無料ですが、公式料金ページ（2026年10月4日閲覧）ではFreeプランの月次クレジットは「0（packs only）」と記載されています。つまり毎月自動で付与されるクレジットはなく、生成するにはクレジットパック（25ドル〜）を購入するか、有料プランに加入する必要があります。

新しいPikaの料金はいくらですか？＋

公式料金ページによると、Starterが月10ドル（年払いなら月8ドル相当）で900クレジット、Creatorが月35ドル（同28ドル）で3,150クレジット、Fancyが月95〜880ドル（同76〜704ドル）で8,550クレジット以上です。年払いは20%割引。追加のクレジットパックは全プラン共通で1ドルあたり60クレジットです。

Pikaで作った動画は商用利用できますか？＋

公式料金ページの比較表では、商用ライセンス（Commercial license）はCreatorプラン以上に含まれ、FreeとStarterには含まれないと記載されています。仕事や収益化目的で使う場合はCreator以上が前提になります。詳細な条件は公式の利用規約で確認してください。

旧Pikaのアカウントやサブスクリプションはどうなりますか？＋

公式ブログ（2026年9月17日）によると、同じログインがそのまま使え、サブスクリプションも「同じプラン・同じ価格」で引き継がれます。有料会員の過去の生成物は「OG Pika」プロジェクトに表示されます。旧インターフェースは old.pika.art に「あと数週間」残り、終了前に告知するとされています。

新しいPikaではどのモデルが使えますか？＋

公式サイトのモデル一覧には、動画でSeedance 2.5・MiniMax H3・Wan 3.0・Google Omni Flash・Pika 2.5・Pikaframes、画像でGPT Image 2.5・Nano Banana・Seedream 5・Grok Imagineなど、音声でPika Speech・Pika Music・Pika Soundtrack・Pika SFX・ElevenLabsのモデルなどが掲載されています。公式は「全ユーザーが全モデル・全アプリを使える」と説明しています。
